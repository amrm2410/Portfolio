# Project: Amr Portfolio

## Structure

- `frontend/` — Next.js 15 app (TypeScript, Tailwind v4), statically exported
- `docs/` — project documentation

## Running the App

### Frontend (Next.js)

```powershell
cd frontend
npm run dev
```

Runs on `http://localhost:3001`.

## Build

```powershell
cd frontend
npm run build
```

Outputs a static export to `frontend/out/`.
